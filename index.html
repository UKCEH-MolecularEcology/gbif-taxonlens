Command-Line & Reproducible Workflows

GBIF TaxonLens is engineered with deduplicated caching and throttled request queue algorithms. Run large checklists securely via Google Colab or locally in your bash/zsh shell terminal.

  • Deduplicates redundant taxonomic strings before query execution.
  • Protects public GBIF nodes using an asynchronous throttled concurrency pool.
  • Exports discrete location audits and occurrence points directly to standard tidy data sheets.
Launch Notebook in Colab
bash — taxonlens.py examples
Run Standard Checklist Match 
python3 cli/taxonlens.py input.csv --default-kingdom Plantae --out matched.csv
Run Match with Geographic QA Validation 
python3 cli/taxonlens.py input.csv --location-check --out matched.csv --location-summary-out locations.csv --occurrences-out occurrences.csv
Custom Concurrent Performance 
python3 cli/taxonlens.py input.csv --concurrency 8 --out matched.csv

Quick Integration Guide

To match your taxonomic checklist against the GBIF backbone, you must map at least the Scientific Name or Genus fields. Adding geographical coordinates (Decimal Latitude & Decimal Longitude) allows spatial plausibility and location audit checks.
