Notebook and terminal workflow

New users can run the Colab notebook without installing anything. Advanced users can run the same matcher from a terminal for large, reproducible batch jobs.

  • Deduplicates repeated names before calling GBIF.
  • Uses a throttled parallel queue for large taxonomy tables.
  • Can export GBIF matches, location summaries, and nearby occurrence records.
Open Colab notebook
Quick match 
python3 cli/taxonlens.py input.csv --default-kingdom Plantae --out matched.csv
Large table 
python3 cli/taxonlens.py input.csv --concurrency 8 --out matched.csv
Location outputs 
python3 cli/taxonlens.py input.csv --location-check --out matched.csv --location-summary-out locations.csv --occurrences-out occurrences.csv
